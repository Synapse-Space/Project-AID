islrtc.nic.in. The words and videos are not served as individually
addressable HTML pages.

## Recommendations for Task 8 (scraper) and Task 9 (wordmap)

1. **Do not scrape `islrtc.nic.in/isl-dictionary/` for per-word content.**
   The page is a PDF flipbook, not an HTML index. There is nothing there
   to parse per-word.
2. **Primary source should be data.gov.in.** Next step before writing a
   scraper: open the OGD catalog page, pull the dataset resource URL(s),
   and confirm the license. If it's OGD India, redistribution is
   explicitly permitted with attribution — this resolves the licensing
   question and skips the scraper entirely.
3. **If OGD dataset is incomplete**, fall back to harvesting the official
   ISLRTC YouTube playlist (`PLFjydPMg4Daoq83bOFHLos3RmcAbfP1vF`) via
   `yt-dlp` or the YouTube Data API, using video titles as the word key.
   Streaming playback from YouTube (no redistribution) is the safe mode.
4. **Do not pursue `indiansignlanguage.org`** — Cloudflare challenge + no
   evidence of open license. Treat as a reference only.
5. **Do not pursue `signlanguage.in`** — domain does not resolve.
6. Still send the licensing email in `docs/islrtc_licensing_email.md` —
   it's cheap, and an explicit ISLRTC blessing is more defensible than
   inferring from robots.txt.
